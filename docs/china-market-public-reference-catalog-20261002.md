# 中国招聘市场公开参考目录（2026-10-02）

## 使用边界

本目录只保存公开来源、来源 URL、岗位场景和脱敏后的结构化特征，不保存个人姓名、电话、邮箱、地址、微信、完整简历图片或岗位联系人信息。

这些资料用于：

- 设计中国市场 Agent 的场景规则；
- 构造脱敏/合成评测样本；
- 检查中文简历章节、字段和 JD 硬条件提取；
- 发现不同岗位之间的差异。

它们不是“优秀简历金标准”，也不代表岗位仍在招聘。岗位是否有效必须以来源页面当前状态为准。

## 证据等级

- **Tier 1**：企业或机构官方招聘页面。
- **Tier 2**：高校就业网转发的企业招聘原文。
- **Tier 3**：社区经验帖、简历分享或评论，适合提取结构和争议点，不直接作为正确答案。

## 可提炼的中国市场规则

这些是从多来源交叉后形成的候选规则，仍需招聘人员复核：

1. 简历质量应按目标岗位判断，不能定义一个脱离场景的“最优秀简历”。
2. 技术岗重点是能验证的项目、技术栈和个人负责范围；技术名词堆叠不等于能力证明。
3. 应届生需要明确教育背景、项目、实习/校园经历和求职方向；实习与校园经历不应自动并入工作经历。
4. JD 中的学历、届别、专业和核心技能需要区分硬性条件与优先条件。
5. 推荐人、年龄、性别、照片和详细住址不能默认加入，必须由用户选择并考虑公开版本隐私。
6. “项目做了什么、本人负责什么、结果或验证是什么”是比单纯职责列表更可复核的表达结构。
7. 公开社区中的 Offer 自述、点赞和评论只能作为弱证据，不能直接作为金标准标签。
