## 本轮修复

### 1. 草稿备份与恢复

- 草稿按用户、简历、不可变快照 ID 分开存储。同一用户的两个标签页不再共享一个可互相覆盖的键。
- 只有有待保存修改的标签页会备份。备份读取当前可见内容，而不是较旧的发送队列。
- 编辑、保存失败和离开页面时保留快照；保存成功仅清理当前运行实例及用户选中的恢复快照。
- 后续快照写入失败时保留上一份备份；存储不可用、配额不足等错误有明确提示。
- 对持久化草稿校验用户/简历身份、格式版本、数据结构、日期、有效期、大小；损坏内容不进入编辑器。
- 每份草稿包含产生编辑时的基准数据。恢复时重新读取服务器，合并两侧独立修改。
- 旧格式缺少比较基准时不自动覆盖；要求明确选择完整版本。
- 恢复提示显示实际服务器更新时间，不再将草稿的基准时间当作当前服务器时间。

主要实现：`apps/web/src/features/resume/builder/draft.ts`、`draft-recovery.ts`、`apps/web/src/routes/builder/$resumeId/route.tsx`。

### 2. 并发合并

- 新增领域函数 `packages/resume/src/merge.ts`，通过包导出 `@reactive-resume/resume/merge` 使用。
- 对含稳定 ID 的条目数组按 ID 合并，保留独立新增、删除和不同字段修改。
- 同一字段的不同修改、删除与编辑冲突、不兼容的排序变化会暂停保存。
- 用户选择冲突值来源时，双方无冲突的修改仍然保留。
- 409 后重新读取服务器失败走可恢复的错误分支；不会产生无界重试。
- 旧运行实例的异步保存结果不能清理新实例的备份。

### 3. 同源字体

- 编辑器字体列表只提供已打包字体和 PDF 标准字体。
- 扩展到 20 个字族、66 个字体文件，共 183,263,300 字节（约 183 MB / 175 MiB）。按需请求，不是一次下载全部。
- 除默认和简体中文外，补齐 Open Sans、Source Sans 3、Lato、Vazirmatn，以及日文、韩文、繁中、阿拉伯文、希伯来文、泰文和 Emoji 的回退资源。
- 66 个文件通过字体格式检查；新增 50 个文件的 SHA-256 与下载清单一致，目录中保留 OFL 许可证。
- 字重选择只展示实际打包的字重；旧数据中的其他字重选取最近本地字重，缺少斜体时使用本地正体。
- 已保存但未打包的字体名称仍保留在简历数据中，预览/PDF 按类别使用本地回退；排版面板明确说明替代字体。该变化可能改变旧简历的外观，不能承诺与原字体逐像素一致。
- 上游字体目录仍保留 URL 元数据；这不代表预览/PDF 使用远程字体。验收脚本分别验证目录行为与实际渲染选择。

主要实现：`packages/fonts/src/index.ts`、`local-fonts.json`、`packages/pdf/src/hooks/use-register-fonts.ts`、字体选择器及 `apps/web/public/fonts/`。

### 4. 验收与测试补全

- `release-acceptance-checks.mts` 中失败的布尔检查现在会让进程失败，不能仅输出 `false` 后仍返回成功；加入负向测试。
- 补全简体/繁体中文的恢复、冲突、备份失败和字体替代文案。
- Node PDF 测试通过测试专用适配器将 `/fonts/**` 映射到真实打包文件。继续执行真实渲染、坐标和像素断言，没有把渲染结果 mock 成成功。
- 为新中文字段补充全模板语义覆盖样例。
- 原先部分坐标测试实际记录的是侧栏页眉布局，却声明 `fullWidth: true`。修复后明确请求双栏以保留原坐标基准，另外新增单栏表格坐标和无侧栏背景断言；未批量刷新快照。
- 临时 Playwright 会话和输出目录加入忽略列表。交接证据另存入文档目录。
