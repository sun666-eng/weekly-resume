## 发现并修复

首次实测中，撤销最新一条成功后，再撤销第二条报版本冲突。原因是 PostgreSQL 时间戳可带微秒，而 JavaScript `Date` 截断到毫秒；用读出的时间戳做 SQL 等值匹配，可能无法找到直接前一条动作。修复后以动作 ID 更新直接前驱，以已查询的动作 ID 集合标记撤销范围，保留简历版本锁。重新构建镜像并从浏览器重跑三次连续撤销通过。另补齐展开历史时的中文状态说明。
