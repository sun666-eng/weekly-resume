## 需要你体验的内容（约 10 分钟）

| 顺序 | 操作 | 应看到的结果 | 发现问题时记下 |
| --- | --- | --- | --- |
| 1 | 中文输入法编辑姓名、职位、项目描述；候选词未确认时按回车选词 | 不抢焦点、不提前提交候选字、不漏字或重复字 | 浏览器、输入法、字段、实际文字 |
| 2 | 修改一个字段，等“已保存”，刷新页面 | 内容一致；保存提示易找到且含义明确 | 修改前后文字、状态、是否刷新后丢失 |

| 4 | 上传虚构样例照片，尝试更换、隐藏、显示、删除和撤销；刷新 | 操作含义清晰、照片加载正常、刷新后保留；隐藏不等于删除 | 模板、操作顺序、缩略图与预览是否同时变化 |
| 5 | 不配置 AI，导入虚构 PDF 或 .docx；若出现复核提示，分别取消和继续 | Word 默认基础导入；取消不创建简历；继续后核对职位、学历与专业；正常文件不一定提示 | 文件类型、提示内容、疑似错位字段 |

## 怎么反馈

每个问题提供四项即可：

1. 测试地址和模板。
2. 操作顺序（如“换照片 → 删除 → 撤销 → 刷新”）。
3. 预期结果与实际结果。
4. 截图，或故障出现的大致时间。

不要发送密码、真实 API Key 或完整私人简历。觉得按钮难找、文案不明白、撤销结果出乎意料，也属于有效反馈。
